# 02. 목적 (R2)

## 매번 달라지는 입력
| 입력 | 형식 | 허용 값 |
|---|---|---|
| screen | 화면 이름 1개 | 행사 달력 / 행사 상세 / 가게 신청 심사 / 게임 설정 / 손님용 휴대폰 화면 (PRD 4장) |
| keywords | 검색 키워드 | 1~3개 |

고정 입력(매번 같음): prd.md, design.md, story-service.md, story-work.md

## 사용자
| 사람 | 하는 일 | 하네스 직접 실행 |
|---|---|---|
| 나(디자이너) | 실행, 결과 수령 | O |
| 팀장님 | 2단계 분석 컨펌 | X |
| 내부 관계자 | 5단계 컨셉 협의 | X |

## 범위
- story-work.md 1~7단계 전체
- 5단계 "내부 관계자 협의"는 하네스 밖에서 사람이 진행 → 하네스는 확정 시안 번호를 입력받을 때까지 대기

## 완료 기준 (한 문장)
대상 화면 1개의 figma 파일에 390×844 프레임이 1개 이상 있고,
가이드 판정 스크립트의 위반이 0건이며, 팀장님 승인 기록이 1건 있다.
